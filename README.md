# Julli's Library

Protótipo inicial da biblioteca virtual integrado ao universo **Julli doesn't know**, desenvolvido com React, TypeScript, Vite e CSS 3D.

## Executar

Requer Node.js 20.19+ ou 22+.

```bash
npm install
npm run dev
npm run build
```

## Incluído

- Estante com prateleiras e lombadas CSS 3D, destaque no hover e abertura de livros ao clicar.
- Busca por título, autor e gênero; filtros de gênero e status de leitura.
- Modal de livro com sinopse, metadados e progresso.
- Layout responsivo com navegação inferior no celular.
- 12 livros **demonstrativos**: não são leituras reais.
- Páginas de diário e conexões como placeholders, previstas para próximas entregas.

## Publicação

O Vite usa `base: '/julli-library/'`. O deploy no GitHub Pages será configurado em uma etapa futura.

## Privacidade

**Nunca adicionar notas privadas a este repositório público.** Elas não devem entrar no GitHub Pages, nem em arquivos JSON, mesmo com campo `visibility: private`.
